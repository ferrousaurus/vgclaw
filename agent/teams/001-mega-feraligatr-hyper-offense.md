## Change Log

### Accepted Changes
- **Arcanine -> Krookodile** (Intimidate preserved). Set: Close Combat / Knock Off / Snarl / Protect, Careful, Sitrus Berry, 31 HP / 4 Atk / 4 Def / 27 SpD / 0 Spe. Rationale: multi-dimensional Intimidate user -- Knock Off (unique among Intimidate users), Electric immunity, Close Combat 4x on meta Kingambit (#5 usage), Snarl preserved from Arcanine. Atk-light spread justified by Close Combat OHKOing standard Kingambit at 0 Atk SPs.
- **Corviknight -> Metagross**. Set: Zen Headbutt / Ice Punch / Meteor Mash / Protect, Clear Body, Leftovers, 31 HP / 16 Atk / 19 SpD / 0 Spe, Adamant. Rationale: non-Mega third damage dealer (base 135 Atk) that hard-counters Sneasler (#11 usage, Fighting/Poison) -- Poison immune (Steel), Fighting neutral (Steel 2x x Psychic 0.5x = 1x), tanks Close Combat (survives at 58%), OHKOs back with Zen Headbutt 4x (245% overkill at 0 Atk SPs). Also covers Garchomp (#1 usage) via Ice Punch 4x OHKO at 16 Atk SPs. Clear Body ignores opposing Intimidate. Preserves Corviknight's Dragon resist (Steel) and physical walling (base 130 Def). Loses Corviknight's Ground immunity (Flying) and second Tailwind -- Volcarona is now sole Tailwind setter.
- **Item distribution locked (Distribution A):** Sitrus Berry on Krookodile (repeatable pivot heal), Leftovers on Metagross (wallbreaker sustain, +11 HP/turn over 3-4 turns on field), Focus Sash on Sableye (non-negotiable -- 50 base HP needs Sash to function).

### Known structural costs (from swaps)
- **Ground immunity lost:** Corviknight's Flying type was the team's only Ground immunity. Metagross is 2x weak to Ground. Krookodile resists Ground (0.5x), Volcarona is immune (Flying) -- partial mitigation but no safe EQ switch-in for Metagross itself.
- **Tailwind dependency increased:** Volcarona is now the sole Tailwind setter. If Volcarona goes down, no speed control. Metagross at 0 Spe SPs (90 Spe) needs Tailwind to outspeed Garchomp/Sneasler.
- **Sun Charizard-Mega-Y matchup lost:** Sun-boosted Heat Wave OHKOs Metagross regardless of item. Corviknight had the same 2x Fire weakness, so this is not a regression -- but it remains an open hole.
